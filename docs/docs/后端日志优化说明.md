## 🌟 新增功能

### 1. SessionID追踪
每次对话生成唯一的SessionID（8位UUID），方便日志追踪和问题定位

```java
String sessionId = java.util.UUID.randomUUID().toString().substring(0, 8);
```

### 2. 完整文字输出
流式对话完成后，自动打印完整回复内容

```java
StringBuilder fullContent = new StringBuilder();
// 累积每个chunk
fullContent.append(content);
// 最后打印完整内容
log.info("📝 [完整回复]:\n{}", fullContent.toString());
```

### 3. 性能统计
- 记录开始和结束时间
- 计算总耗时（毫秒和秒）
- 统计接收的数据块数量

```java
long startTime = System.currentTimeMillis();
// ... 处理 ...
long duration = endTime - startTime;
log.info("⏱️  [耗时]: {} ms ({} 秒)", duration, String.format("%.2f", duration / 1000.0));
```

### 4. Token用量统计
清晰展示输入、输出和总Token数量

```java
log.info("💰 [Token用量]:");
log.info("   • 输入 Tokens: {}", message.getUsage().getInputTokens());
log.info("   • 输出 Tokens: {}", message.getUsage().getOutputTokens());
log.info("   • 总 Tokens: {}", message.getUsage().getTotalTokens());
```

### 5. 错误处理增强
详细的错误日志，包含SessionID、耗时、错误信息

```java
.doOnError(error -> {
    log.error("❌ [流式对话失败] SessionID: {}", sessionId);
    log.error("❌ [错误信息]: {}", error.getMessage());
    log.error("=".repeat(80) + "\n", error);
})
```

## 📋 日志级别说明

### Emoji图标含义
- 🚀 开始操作
- ✅ 成功完成
- ❌ 失败/错误
- 📥 输入/接收
- 📝 内容/文本
- ⚙️ 配置
- 🔗 连接/调用
- ⏱️ 时间/性能
- 📊 统计数据
- 💰 资源消耗
- 🏁 结束标记
- ⚠️ 警告
- 🎭 角色
- 📚 文档链接

## 🎨 日志格式规范

### 分隔线
```java
"=".repeat(80)  // 80个等号，清晰分隔不同对话
```

### 标题格式
```java
log.info("🚀 [操作名称] 描述信息");
```

### 内容格式
```java
log.info("📝 [标签]: 内容");
log.info("   • 子项1: 值1");  // 使用缩进和项目符号
log.info("   • 子项2: 值2");
```
