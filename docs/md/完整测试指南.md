## 四、常见问题排查

### 问题1：JD生成失败

**错误信息**：`LLM调用失败`

**排查步骤**：
1. 检查环境变量：`echo $DASHSCOPE_API_KEY`
2. 检查application.yml中的api-key配置
3. 检查网络连接
4. 查看详细错误日志

**解决方案**：
```bash
export DASHSCOPE_API_KEY=your_api_key
```

### 问题2：简历解析失败

**错误信息**：`PDF解析失败`

**排查步骤**：
1. 检查文件格式（PDF/Word）
2. 检查文件大小（<200MB）
3. 检查上传目录权限
4. 查看parse_error字段

**解决方案**：
```bash
mkdir -p /tmp/resumes
chmod 777 /tmp/resumes
```

### 问题3：混合检索无结果

**原因**：ES或Milvus中无数据

**解决方案**：
1. 先上传几份简历
2. 等待Kafka异步处理完成（~15秒）
3. 检查ES索引：`curl http://localhost:9200/candidate_resume/_count`
4. 再次执行检索

### 问题4：Kafka消息积压

**排查**：访问 http://localhost:8090 查看Consumer Lag

**解决方案**：
1. 增加消费者并发度（application.yml）
2. 检查消费者是否有异常
3. 查看死信队列

### 问题5：端到端测试超时

**原因**：LLM调用慢或网络问题

**解决方案**：
1. 检查网络
2. 检查LLM API配额
3. 降低温度参数（temperature）加快响应
