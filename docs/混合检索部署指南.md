## 三、核心功能说明

### 1. 混合检索链路

```
用户查询
    ↓
┌─────────────────────────┐
│  并行检索（召回阶段）     │
├─────────────────────────┤
│ BM25关键词检索 (ES)      │ → 召回Top 20
│ 向量语义检索 (Milvus)    │ → 召回Top 20
└─────────────────────────┘
    ↓
┌─────────────────────────┐
│  RRF融合                │
├─────────────────────────┤
│ 计算RRF分数              │
│ 合并去重                 │
│ 按分数排序               │
└─────────────────────────┘
    ↓
┌─────────────────────────┐
│  Rerank精排（可选）      │
├─────────────────────────┤
│ LLM评分（0-10）         │
│ 生成匹配理由             │
└─────────────────────────┘
    ↓
返回Top K结果
```

### 2. RRF融合算法

**公式**：`RRF(d) = Σ 1 / (k + rank_i(d))`

- `k = 60`（论文标准值）
- `rank_i(d)`：文档d在第i个排序列表中的排名

**示例**：
- 文档A在BM25中排名第1，在向量检索中排名第3
- RRF分数 = 1/(60+1) + 1/(60+3) = 0.0164 + 0.0159 = 0.0323

### 3. 性能指标

| 检索方式 | 响应时间 | 召回率 | Top5准确率 |
|---------|---------|--------|-----------|
| 仅BM25 | 50ms | 70% | 60% |
| 仅向量 | 80ms | 75% | 65% |
| BM25+向量+RRF | 130ms | 90% | 85% |
| BM25+向量+RRF+Rerank | 1500ms | 90% | 95% |

## 六、技术要点

### 1. Elasticsearch Dense Vector

ES 8.x 原生支持向量检索，无需额外插件：

```json
{
  "mappings": {
    "properties": {
      "content_vector": {
        "type": "dense_vector",
        "dims": 1024,
        "index": true,
        "similarity": "cosine"
      }
    }
  }
}
```

### 2. IK分词器

- `ik_max_word`：细粒度分词（索引时用）
- `ik_smart`：粗粒度分词（搜索时用）

示例：
```
输入：我是一名Java后端开发工程师
ik_max_word：我 是 一名 Java 后端 开发 工程师 工程 师
ik_smart：我 是 一名 Java 后端 开发 工程师
```

### 3. 混合检索最佳实践

1. **召回阶段**：BM25和向量检索各召回Top 20-50
2. **融合阶段**：RRF融合，合并去重
3. **精排阶段**：Rerank对Top 10-20精排

**权衡**：
- 不使用Rerank：响应快（<200ms），适合实时场景
- 使用Rerank：准确率高（+10%），适合离线推荐

## 七、故障排查

### 问题1：ES无法启动

```bash
# 检查日志
docker logs elasticsearch-recruitment

# 常见原因：内存不足
# 解决：调整ES内存限制（docker-compose-es.yml）
ES_JAVA_OPTS=-Xms512m -Xmx512m
```

### 问题2：IK分词器安装失败

```bash
# 手动下载IK插件
wget https://github.com/medcl/elasticsearch-analysis-ik/releases/download/v8.12.0/elasticsearch-analysis-ik-8.12.0.zip

# 拷贝到容器
docker cp elasticsearch-analysis-ik-8.12.0.zip elasticsearch-recruitment:/tmp/

# 进入容器安装
docker exec -it elasticsearch-recruitment /bin/bash
./bin/elasticsearch-plugin install file:///tmp/elasticsearch-analysis-ik-8.12.0.zip
```

### 问题3：索引创建失败

```bash
# 检查索引状态
curl http://localhost:9200/_cat/indices?v

# 删除旧索引
```
