# 限流功能说明文档

## 🎯 功能概述

为 `/ali/chat/stream` 流式对话接口添加了**双层限流机制**，防止恶意请求和服务过载。

---

## 🏗️ 架构设计

### 限流层级
```
请求 → 全局限流 → 用户限流 → 业务处理
       (10次/秒)   (2次/秒)
```

### 限流算法
使用 **Google Guava RateLimiter**，基于**令牌桶算法**：
- 平滑限流，不会出现突刺
- 支持预热和突发流量
- 高性能，无锁实现

---

## 📋 限流规则

### 1. 全局限流
- **速率**: 10 次/秒
- **范围**: 所有用户共享
- **作用**: 保护服务器整体负载
- **超限**: 立即拒绝，不等待

### 2. 用户限流
- **速率**: 2 次/秒
- **范围**: 每个IP独立计算
- **作用**: 防止单个用户占用过多资源
- **超限**: 等待500ms，仍无法获取则拒绝

### 限流判断逻辑
```java
if (!全局限流通过) {
    return "请求过于频繁，请稍后再试";
}

if (!用户限流通过(等待500ms)) {
    return "请求过于频繁，请稍后再试";
}

// 通过限流，执行业务逻辑
```

## 📁 文件清单

### 1. RateLimiterManager.java
**路径**: `xCloud/config/RateLimiterManager.java`

**功能**:
- 管理全局和用户级别的限流器
- 提供限流检查方法
- 自动清理不活跃的用户限流器

**核心方法**:
```java
// 组合限流检查（全局 + 用户）
public boolean tryAcquire(String userId)

// 全局限流检查
public boolean tryAcquireGlobal(long timeout)

// 用户限流检查
public boolean tryAcquireUser(String userId, long timeout)

// 清理不活跃的限流器
public void cleanupInactiveUserLimiters()
```

### 2. IpUtil.java
**路径**: `xCloud/util/IpUtil.java`

**功能**:
- 获取客户端真实IP地址
- 支持多种代理和负载均衡场景

**支持的Header**:
- X-Forwarded-For
- X-Real-IP
- Proxy-Client-IP
- WL-Proxy-Client-IP
- HTTP_CLIENT_IP
- HTTP_X_FORWARDED_FOR

### 3. AliChatController.java (修改)
**路径**: `xCloud/controller/AliChatController.java`

**修改内容**:
- 注入 `RateLimiterManager`
- 在 `streamChat` 方法中添加限流检查
- 获取客户端IP并记录日志
- 限流失败返回友好提示

### 4. pom.xml (修改)
**添加依赖**:

## ⚙️ 配置参数

可以在 `RateLimiterManager.java` 中调整限流参数：

```java
// 全局限流：每秒允许的请求数
private final RateLimiter globalRateLimiter = RateLimiter.create(10.0);

// 用户限流：每秒允许的请求数
private static final double USER_PERMITS_PER_SECOND = 2.0;
```

### 调整建议

| 场景 | 全局限流 | 用户限流 | 说明 |
|------|---------|---------|------|
| 开发环境 | 100/秒 | 10/秒 | 宽松限制，方便测试 |
| 测试环境 | 50/秒 | 5/秒 | 模拟生产压力 |
| 生产环境 | 10/秒 | 2/秒 | 严格限制，保护服务 |
| 高并发场景 | 50/秒 | 5/秒 | 根据服务器性能调整 |

## 🔧 扩展功能

### 1. Redis分布式限流（推荐生产环境）
```java
@Component
public class RedisRateLimiter {
    @Autowired
    private RedisTemplate<String, String> redisTemplate;
    
    public boolean tryAcquire(String key, int limit, int seconds) {
        String redisKey = "rate_limit:" + key;
        Long count = redisTemplate.opsForValue().increment(redisKey);
        
        if (count == 1) {
            redisTemplate.expire(redisKey, seconds, TimeUnit.SECONDS);
        }
        
        return count <= limit;
    }
}
```

## 🐛 故障排查

### 问题1：所有请求都被限流
**原因**: 限流参数设置过小
**解决**: 调整 `globalRateLimiter` 和 `USER_PERMITS_PER_SECOND` 参数

### 问题2：同一用户不同IP被限流
**原因**: 使用了代理或负载均衡
**解决**: 检查 `IpUtil.getClientIp()` 是否正确获取真实IP

### 问题3：内存占用过高
**原因**: 用户限流器未清理
**解决**: 定期调用 `cleanupInactiveUserLimiters()`
